# 雙平面穿越時間血流量測演算法（現行版本）

> 對應程式：`main.m`、`+src/estimate_slice.m`、`+src/through_plane.m`
> 最後更新：2026-10-08

## 0. 資料與座標

- 探頭上有兩個成像平面 **row1、row2**，沿掃描軸（y）固定間隔 `d_row`；row2 在探頭 +y 側。
- 模擬：`d_row = 2.670 mm`、`Nt = 512` frames、`dt = 0.4 ms`、像素 `dx = dz = 50 µm`、elevation beam `σy = 0.6 mm`。
- 每個切片檔含兩平面的複數 IQ。預設用 envelope（`abs(IQ)`）做穿越相關；實驗資料可改用複數 IQ（見 §5）。

---

## 1. 量測層（直管、狹窄管共用）

### 1.1 ROI 撒點
- 以 0.25 mm 網格在管腔內撒 ROI，每個 ROI 為 **0.5 × 0.5 mm**（≈ 一顆散斑）。
- **能量閘**：ROI 在管外的回波能量超過管內的 25% 就剔除（防止騎牆 ROI 把組織混進血流）。
- **壁淨空**（`wall_margin_mm = 0.25`，即一個窗半寬）：ROI 中心離**局部管壁**不足 0.25 mm 就不撒——量測窗不得跨出管壁。跨壁窗是結構性混合訊號（壁邊慢血＋PSF 暈入的較快鄰血＋管外暗區），事後審查（cc、突出度、可重複性）全部驗不出它——它量到的是「真實的穿越、錯誤的地址」。五個驗證資料集上，全部倖存假點 100% 住在這條環裡。壁環由補值層（no-slip 零錨點＋內圈量測＋剖面模型）接管。淨空隨局部半徑自動縮放（喉部一樣適用）。

### 1.2 穿越時間 NCC
每個 ROI 獨立作業：

1. 取 row1 的 ROI 內容當**模板**。
2. 對每個候選 lag `L`，把模板與 row2 在 `t+L` 的視窗做 ZNCC，**對全部 frame 對取 ensemble 平均**——單對會被巧合相似騙，平均考的是可重複性。
3. 所有 lag 的平均值連成 **CC 曲線**，取峰。
4. **門檻**：峰高 `cc ≥ 0.5`、峰不能落在掃描範圍邊緣。相對突出度只對極長 lag（> 1200 幀）的峰檢查；絕對突出度 `prom_abs_min` 預設關（實驗用，見 §5）。
5. **Sub-pixel**：整數峰 ± 1 點做三點拋物線擬合 → 非整數峰位。
6. **峰形閘門（sharp，選配，預設關）**：真穿越峰的「寬度/位置」比值由 σy/d_row 決定，無量綱銳度 `sharp = curv×lag²/cc` 應落在 (d_row/σy)²≈19.8 附近；過平＝停滯散斑、過尖＝雜訊漣漪。壁淨空已從源頭移除它的主要獵物，且實驗上 σy 難以精確提供，故不啟用。
7. 速度 `vy = d_row / (lag × dt)`。

**lag 掃描範圍**由每個資料集自動決定（`AutoLags`）：以中心最快的穿越 lag `L = d_row / (vmax·dt)`，掃 `0.5L ~ 12L`。

> 鐵律：**取峰之前，不把不同空間位置的資訊混在一起**——位置差會變成速度偏差。
> （時間上的 ensemble 平均不違反：同一位置、每個時刻答案本來就相同。）

### 1.3 Stage B 細掃
峰附近用單散斑小窗（**0.6 × 0.3 mm**，側向 × 軸向）重新掃一次，只用自己的曲線取峰（鄰居曲線平均已移除，`vy_spatial_half = 0`：直管全腔 NRMSE 5.4% → 2.7%）。

### 1.4 反向流掃描（預設關）
負 lag 掃描的門檻只有顯著性、沒有 cc_min，會從正向失敗的窗收進雜訊峰（sten20 下游：11% 的有效點貢獻 99% 的平方誤差）。目前關閉，洞交給補值層。

## 2. 狹窄管專屬：搜尋窗位移候選賽跑

收縮段的散斑在飛越途中會往軸心漂移，row2 的搜尋窗必須跟著移。三個候選同時掃 CC 曲線，**峰最高者當選**：

| 候選 | 位移來源 | 適用 |
|---|---|---|
| 零位移 | 原地等 | 直管（自動勝出） |
| 量測補償 | row1 平面內散斑追蹤出 vx、vz，外推飛行漂移 | 只補到真值 ~68%（出發時速度低估全程） |
| **幾何位移** | 管壁形狀：`(1 − R₂/R₁) × 到軸心向量`，免估計 | 只在收縮段啟用；擴張段流分離、假設不成立 |

- 位移上限 clamp：`0.25 × d_row`。
- 直管 `R₁ = R₂` → 幾何候選自動歸零；in-plane 追蹤在直管關閉（auto）。

## 3. 補值層（量不到的近壁環）

量到的點**永遠不動**；洞（被門檻剔除的格子）按以下規則補：

### 3.1 兩位候選補值者
- **內插**：natural-neighbor 內插，來源 = 量到的點 + 管壁一圈 **no-slip 零錨點**。
- **剖面模型**：`v = v₀ (1 − (r/R)ⁿ)`——v₀ = 中心速度、n = 鈍度（n=2 拋物線，n=7~10 平台+懸崖）。以 CC 值加權、soft-L1 穩健損失擬合全部量測點。

### 3.2 考試定權重 w
藏起外圈 20% 量測點當考卷 → 模型與內插各自預測 → 對答案：

```
w = 內插誤差² / (模型誤差² + 內插誤差²)
補值 = w × 模型 + (1 − w) × 內插
```

無手調門檻；模型考爛自動退回內插。

### 3.3 參數沿血管中值濾波
v₀、n、w 每片擬合後，各自取 **±2 片的中位數**再使用。相鄰片僅 0.5 mm，剖面不可能突變；中值讓野值（退化擬合 n=216、考題抽樣的 w 跳水）直接出局。

### 3.4 分離閘門（擴張段，斜坡）
擴張段中，模型權重再乘上 `wSep = clamp((n − 4.5) / 1.0, 0, 1)`：平滑後 n ≥ 5.5 全用模型（噴流仍貼壁），n ≤ 4.5 全用內插（分離環出現），中間線性過渡，約 3 片內完成交接。

原本是 n ≤ 5.5 硬切，換手片會一次跳 −10~−14% 流量（考試權重在門檻前都還是 0.94~0.99，因為考題在核心，模型在那裡仍然對）；改成 5.0 只是把跳點往後移一片。斜坡後相鄰片最大跳動 11~13% → 3~4%。4.5~5.5 涵蓋三個速度的真值交叉點（n = 4.4 / 5.1 / 5.1，20/50/80 cm/s）。校準自單一 seed，待多 seed 驗證。

## 4. 輸出層

### 4.1 SG 平滑（由 n 自動決定開關）
- **平滑後 n < 3**（直管擬出 2.0-2.2）→ 做 2-D Savitzky-Golay：每格取周圍 `SGWindow × SGWindow` 格擬合二次曲面、只取中心值。對拋物線零失真，純降噪（raw 7.0% → 2.7%）。
- **n ≥ 3**（鈍頭，狹窄管全部片）→ 跳過 SG，補值場即最終場（二次曲面會抹平懸崖）。

### 4.2 流量
最終場對截面積分：`Q = Σ v × cell_area`。真值比對：速度場對**路徑真值**（transit truth）、流量對 **row1 平面真值**（通量守恆的量）。

## 5. 實驗資料選項（預設全關，模擬結果不受影響）

| 選項 | 作用 |
|---|---|
| `transit_cc = 'coherent'` | 用複數 IQ 做穿越相關（conj 乘積的模）。實驗上 envelope 相關會被 clutter 的亮度共模淹沒，複數相關仍鎖得住 |
| `slow_time_filter` | `'mean'`（每像素扣慢時間平均）或 `'svd'`（Casorati 矩陣去掉前 `svd_ncut` 個奇異成分，同時去掉組織與振動） |
| `row2_offset_mm`、`row2_offset_table` | row2 相對 row1 的固定平面位移（管子傾斜），可每片不同；仍與零位移賽跑。**要從血流量，不能用轉檔的組織配準** |
| `prom_abs_min` | 峰須高出整條曲線中位數至少這麼多，擋掉平坦曲線的小漣漪 |
| `d_row_table` | 依深度的兩排有效距離（官方表 `[10 3.07; 20 1.51; 25 1.25]` mm），每個 ROI 依自身深度換算 |

轉檔後的切片檔需先補上 `d_row`、`sigma_y`、`flow_direction`。資料若是分段收集（例如每段 100 幀），跨段的 frame 對不連續，應排除。

## 6. 目前成績

**模擬**（直管 5 seeds；狹窄管 seed 100，`results/sten_ramp`、`results/sten50`）

| 條件 | 全腔 NRMSE | 流量誤差 |
|---|---|---|
| 直管 20 / 50 / 80 / 100 cm/s | 2.4 / 2.3 / 2.2 / 2.0 % | +1.1 / +1.2 / +1.1 / +0.9 % |
| 直管 20 cm/s + 3-D 組織（無濾波） | 2.5 % | +1.1 % |
| 50% 狹窄 20 / 50 / 80 cm/s | 8.4 / 8.6 / 8.5 % | 平均 \|誤差\| 9.6 / 8.4 / 7.7 % |
| 50% 狹窄 100 cm/s | 12.2 % | 平均 \|誤差\| 11.7 % |

50% 狹窄分段：上游 NRMSE 5–6%、流量 +9~10%；喉部 6–8%、±2%；下游貼壁段 8–12%；下游回流段 13–19%，流量最高 +21~26%（100 cm/s 到 +44%）。

**75% 狹窄**（`results/sten75`）：超出方法適用範圍，全腔 NRMSE 23–30%，見 §7。

**實驗**

| 資料 | 結果 |
|---|---|
| 260827（14 mm 深） | 尺度均勻偏 ×2；以 ×0.5 校正後盲測 245 vs 流量計 240（+2%） |
| 260904-f378（1430 仿體，4 mm 管，22.8 mm 深） | 有清楚穿越峰（cc 0.38），但流量 611 vs 378（+62%）；中心 ×1.1、外圈 ×1.9。原因未定（見 §7） |
| 260904-f378 10 kHz / 100 幀 | 流量 618：lag 量化細 4 倍、結果不變 → 不是量化誤差 |
| 261004 run1（~120 mL/min，粗管） | 兩排之間找不到穿越峰（cc 0.06） |

## 7. 已知限制與待辦

**模擬**
- **狹窄下游回流段**：近壁一圈先停滯再回流，量不到（可測比例 55% → 33%），補值假設它仍在流動 → 流量高估 +21~26%。慢流最嚴重，因為慢流的邊界層相對較厚（尾段貼壁環/核心真值比 20/50/80 cm/s = 11/19/23%）。這是流場性質，不是演算法差異。
- **收縮段流量 +9~10%**：transit 量的是路徑平均、流量要截面值的幾何效應；有純幾何換算解法，暫緩。
- **兩排間縮率上限**：兩排之間管徑縮超過 ~20%，散斑在飛行途中被壓縮變形，cc 掉到門檻以下（50% 狹窄最大 15%，全部可測；75% 狹窄達 28%，收縮段 12 片完全量不到）。這是雙排穿越法的固有限制，與狹窄程度無關，取決於收縮陡度。75% 喉部另有剪切層問題：外圈 69% 面積靠補值，流量 −30%。
- **斜坡門檻待驗證**：用 `sim_stenosis50_80cms` seeds 200–500 檢查 4.5~5.5 是否穩定。
- 校準常數看板：分離斜坡 `n = 4.5~5.5`、SG 開關 `n = 3.0`。

**實驗**
- **f378 高估的原因未定**。候選：(1) 兩排同時發射造成的中平面鬼影（外圈 ×2，與 260827 的 ×0.5 一致，但從未直接觀測）；(2) 散斑在飛行途中去相關，把峰拉向短 lag（外圈飛得久、拉得多）；(3) 兩排有效距離 `d_row_table` 在該深度不準；(4) 流量計讀數或層流假設不準（實測剖面幾乎是平的）。已確認散斑確實有流到 row2（row1 自相關 1.2 ms 降到 0.12，同時刻跨排峰 0.41）。
- **計畫中的流量掃描**（1430 仿體，固定探頭，30–378 mL/min）：純穿越時 `lag × Q` 為常數；低流量時若變小、峰變矮，即途中去相關。可區分 (2)，但區分不了 (1)。
- **慢流**：中心穿越時間 `T ≈ 30π·d·R²/Q` ms（d、R 單位 mm，Q 單位 mL/min）需短於散斑存活時間；261004 估計 ~23 ms，而散斑 5–7 ms 就換掉，故找不到峰。
- **兩排有效距離與 σy 從未實測**：需細線掃描。鬼影則可用拔 port 的靜態對照實驗直接量。
- 單一常數的鬼影校正（外圈 ×0.5）不在主線，已移除。
