# 雙平面穿越時間血流量測演算法（現行版本）

> 對應程式：`main.m`、`+src/estimate_slice.m`、`+src/through_plane.m`、`+src/localize_scan.m`
> 最後更新：2026-08-29

## 0. 資料與座標

- 探頭上有兩個成像平面 **row1、row2**，沿掃描軸（y）固定間隔 `d_row = 2.670 mm`；row2 在探頭 +y 側。
- 每個掃描位置收 `Nt = 512` frames，`dt = 0.4 ms`，像素 `dx = dz = 50 µm`，elevation beam `σy = 0.6 mm`。
- 每個切片檔含兩平面的複數 IQ；演算法用 envelope（`abs(IQ)`）。

---

## 1. 量測層（直管、狹窄管共用）

### 1.1 ROI 撒點
- 以 0.25 mm 網格在管腔內撒 ROI，每個 ROI 為 **0.5 × 0.5 mm**（≈ 一顆散斑）。
- **能量閘**：ROI 在管外的回波能量超過管內的 25% 就剔除（防止騎牆 ROI 把組織混進血流）。
- **壁淨空**（`wall_margin_mm = 0.25`，即一個窗半寬）：ROI 中心離**局部管壁**不足 0.25 mm 就不撒——量測窗不得跨出管壁。跨壁窗是結構性混合訊號（壁邊慢血＋PSF 暈入的較快鄰血＋管外暗區），事後審查（cc、突出度、可重複性）全部驗不出它——它量到的是「真實的穿越、錯誤的地址」。五個驗證資料集上，全部倖存假點 100% 住在這條環裡，陪葬的誠實點自身中位誤差 16~42%。壁環在最終場照樣存在，由補值層（no-slip 零錨點＋內圈量測＋剖面模型）接管；實測撤掉壁環證人後補值品質持平或更好。淨空隨局部半徑自動縮放（喉部一樣適用）。

### 1.2 穿越時間 NCC
每個 ROI 獨立作業：

1. 取 row1 的 ROI 內容當**模板（ref）**。
2. 對每個候選 lag `L`，把模板與 row2 在 `t+L` 的視窗做 ZNCC，**對全部 frame 對（約 500 對）取 ensemble 平均**——單對會被巧合相似騙，平均考的是可重複性。
3. 所有 lag 的平均值連成 **CC 曲線**，取峰。
4. **三道門檻**：峰高 `cc ≥ 0.5`；峰的突出度（prominence）；前半/後半 ensemble 各自算一次要一致（可重複性）。
5. **Sub-pixel**：整數峰 ± 1 點做三點拋物線擬合 → 非整數峰位。
6. **峰形閘門（sharp，選配，預設關）**：真穿越峰的「寬度/位置」比值被硬體鎖死為 σy/d_row，無量綱銳度 `sharp = curv×lag²/cc` 應落在 (d_row/σy)²≈19.8 附近（帶 [10,45]）；過平＝停滯散斑自相關、過尖＝雜訊漣漪。**現行配置不啟用**——壁淨空已從源頭移除了它的主要獵物（乾淨模擬中假點 100% 住壁環），且實驗上 σy 難以精確提供。保留作為兩種情境的備援：管壁分割不準（騎牆窗溜回來）、或管腔內部出現 clutter 凍結高原（實驗組織/混響）。
7. 速度 `vy = d_row / (lag × dt)`。

> 鐵律：**取峰之前，不把不同空間位置的資訊混在一起**——位置差會變成速度偏差。
> （時間上的 ensemble 平均不違反：同一位置、每個時刻答案本來就相同。）

### 1.3 Stage B 細掃
峰附近用單散斑小窗（0.3 × 0.15 mm）重新掃一次，只用自己的曲線取峰（鄰居曲線平均已移除，`vy_spatial_half = 0`）。

## 2. 狹窄管專屬：搜尋窗位移候選賽跑

收縮段的散斑在飛越途中會往軸心漂移，row2 的搜尋窗必須跟著移。三個候選同時掃 CC 曲線，**峰最高者當選**：

| 候選 | 位移來源 | 適用 |
|---|---|---|
| 零位移 | 原地等 | 直管（自動勝出） |
| 量測補償 | row1 平面內散斑追蹤出 vx、vz，外推飛行漂移 | 但只補到真值 ~68%（出發時速度低估全程） |
| **幾何位移** | 管壁形狀：`(1 − R₂/R₁) × 到軸心向量`，免估計 | 只在收縮段啟用（`contr ≥ 0`）；擴張段流分離、假設不成立 |

- 位移上限 clamp：`0.25 × d_row`。
- 直管 `R₁ = R₂` → 幾何候選自動歸零；in-plane 追蹤在直管關閉（auto）。

## 3. 補值層（量不到的近壁環）

量到的點**永遠不動**；洞（被門檻剔除的格子）按以下規則補：

### 3.1 兩位候選補值者
- **內插**：natural-neighbor 內插，來源 = 量到的點 + 管壁一圈 **no-slip 零錨點**（v=0 是物理邊界條件）。所有洞一次算完，不用二手補值。
- **剖面模型**：`v = v₀ (1 − (r/R)ⁿ)`——v₀ = 曲線高度（中心速度）、n = 鈍度（n=2 拋物線，n=7~10 平台+懸崖）。以 CC 值加權、soft-L1 穩健損失擬合全部量測點。

### 3.2 考試定權重 w
藏起外圈 20% 量測點當考卷 → 模型與內插各自預測 → 對答案：

```
w = 內插誤差² / (模型誤差² + 內插誤差²)
補值 = w × 模型 + (1 − w) × 內插
```

無手調門檻；模型考爛自動退回內插。

### 3.3 參數沿血管中值濾波
v₀、n、w 每片擬合後，各自取 **±2 片的中位數**再使用。相鄰片僅 0.5 mm，剖面不可能突變；中值讓野值（退化擬合 n=216、考題抽樣的 w 跳水）直接出局，平滑段落原樣保留。NaN 不傳染。

### 3.4 分離閘門（擴張段）
管徑沿流向變寬時，模型只有在**量測剖面仍是鈍頭（平滑後 n > 5.5）**時可用——n 高 = 噴流仍貼壁；n 掉到 ~4.6-5.0 = 分離環出現，改用純內插（近壁真的慢，拉直線反而接近事實）。
5.5 校準自本血管單一 seed，是要在多 seed 監控的常數。

## 4. 輸出層

### 4.1 SG 平滑（由 n 自動決定開關）
- **平滑後 n < 3**（二次相容，直管擬出 2.0-2.2）→ 做 2-D Savitzky-Golay：每格取周圍 `SGWindow × SGWindow` 格（直管用 11 = 2.75 mm）擬合二次曲面、只取曲面中心值。對拋物線零失真，純降噪（raw 7.0% → 2.7%）。
- **n ≥ 3**（鈍頭，狹窄管全部片）→ 跳過 SG，補值場即最終場——二次曲面會抹平懸崖（實測 10.5→10.8~11.2%），且模型補的洞本來就光滑。
- 無擬合的片退回錐形管代理判斷（`compensate_xz`）。

### 4.2 流量
最終場對截面積分：`Q = Σ v × cell_area`。真值比對：速度場對**路徑真值**（transit truth）、流量對 **row1 平面真值**（通量守恆的量）。

## 5. 定位層（組織 → 探頭方向與步距）

背景組織是靜態的 → 當位置基準。慣例**寫死**：

```
ref   = row2（永遠）      moved = row1（永遠）
峰在 +m → 探頭朝 row2 側掃；峰在 −m → 朝 row1 側掃
|峰位| × 步距 = d_row  →  步距 = d_row / |峰位|
```

流程（`src.localize_scan`，main 內建 stage）：
1. 每片取一個 frame 的兩張 envelope 快照（在 `estimate_slice` 讀檔時順手留，I/O 零增加）。
2. 遮罩：排除 `r < 1.3R`（血會動）；每列去均值（拆掉分層亮帶共模）。
3. `NCC(row2[k], row1[k+m])` 掃 `m = ±8`（`|m| ≤ 1` 排除：鄰片 beam 重疊天然相關）。
4. 峰用**扣基線 + 高斯**三點擬合（拋物線會 peak-locking，−0.7% → −0.08%）。
5. 掃描尾端 ~`d_row/步距` 片沒有前向夥伴 → 自動**鏡像配對**（`row1[k]` 對 `row2[j]`，符號翻回）。
6. 自動閘門：管外/管內能量比 < 0.05（乾淨模擬）→ 整段跳過。

**Block matching 模式**（`loc_search_mm > 0`，預設 0 = 關）：同位置 NCC 假設探頭只沿 y 平移；實驗上探頭壓力與仿體表面凹凸會讓組織在平面內錯位。開啟後改用古典 block matching——取 `loc_blocks`（3）塊 `loc_block_mm`（2mm）組織小塊，每塊在 ±`loc_search_mm` 的窗內對每個切片位移取最佳 ZNCC，塊間取中位數且需多數同意。窗內取 max 會抬高雜訊底，故峰要高出自身曲線底 **4 倍穩健離散度**才算數——這個閘門同時守住掃描尾端的鏡像 fallback（偽峰擋掉，才輪得到鏡像配對）。組織資料實測：乾淨 41/41、步距 0.4991±0.0050mm（比同位置模式 40/41、±0.024 更好）；合成每片 0.05~0.35mm 錯位下同位置模式崩到 30/41，block 模式不動如山 41/41。

輸出 `localization.csv`（每步的 direction / step_mm / cc_peak / pairing）；**只報告、不介入**——truth 比對仍用 manifest 座標，定位誤差不進速度誤差帳。3-D 重建（viz 層）才是消費者。

## 6. 3-D 重建（M3）

```
組織定位 → 疊圖方向 + 每步 y 座標
血流量測 → 每片 (x,z) 速度場
合體     → 3-D 血管：座標、速度分布、每片流量（守恆自檢）
```

## 8. 已知限制與待辦

- **狹窄下游分離區**（sl29+）：80 cm/s 是純量測極限（raw 5%,洞佔 58%）;20/50 另有分離區內部的準凍結慢流答案污染量測(raw 18-24%)——M4 reverse scan 重做時一併審理(屆時可評估 sharp 只開下游)。full 14.5-28%。
- **收縮段 flow +8~11%**：transit 量的是路徑平均、流量要截面值的幾何效應；有純幾何換算解法，暫緩。
- **組織亮度**：現行模擬組織比血暗（符合本實驗仿體）；活體條件（組織 +20~40 dB）需 SVD/均值移除，未啟用。
- 校準常數看板（多 seed 監控）：分離閘門 `n=5.5`、SG 開關 `n=3.0`。
